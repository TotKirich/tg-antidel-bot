# Telegram Delete Guard · V2

Личный архив Telegram: сохраняет входящие сообщения и файлы, историю правок и доступные сторис контактов. При удалении отправляет сохранённую копию в закрытую группу-архив, а уведомления — вашему боту.

**Сохраняются только данные, полученные после запуска сервиса.** Восстановить ранее удалённую переписку или обойти ограничения доступа Telegram нельзя.

## Что изменилось в V2

- **Установка одной командой:** готовый Docker-образ с Python и зависимостями; Docker и Compose устанавливаются автоматически.
- **Настройка через браузер:** API Telegram, вход по QR или коду, подключение бота. Получатель уведомлений определяется автоматически.
- **Устойчивее обработка:** постоянные очереди, повторные попытки, перепроверки удаления, учёт лимитов Telegram и перезапуск процессов.
- **Удобнее архив:** одна закрытая группа, темы по авторам, имена из контактов, отдельные цитаты «Было» и «Стало».
- **Сторис контактов:** сохранение и уведомление при раннем удалении; обычное истечение срока без уведомления.
- **Управление из бота:** включение уведомлений, фильтр удалений из каналов, точечные настройки пабликов, статус и занятое/свободное место на диске, включая файлы.

## Установка

Linux **x86-64**. Для автоматической установки Docker поддерживаются Ubuntu/Debian; нужны Интернет и root/sudo. Если `curl` отсутствует, сначала установите его пакетным менеджером ОС.

```bash
curl -fsSL https://raw.githubusercontent.com/TotKirich/tg-antidel-bot/main/install.sh -o install.sh && bash install.sh
```

Скачиваются три служебных файла и готовый образ. Git, Python и сборка на сервере не нужны. Данные хранятся в `~/tg-antidel-bot/data`.

Откройте **полную ссылку из терминала** и пройдите мастер:

1. Получите **API ID и API hash** на [my.telegram.org/apps](https://my.telegram.org/apps).
2. Войдите в Telegram по QR-коду или коду подтверждения; при необходимости введите пароль 2FA.
3. Создайте бота через [@BotFather](https://t.me/BotFather), введите его токен и нажмите `/start` в своём боте.

После настройки веб-форма закрывается. Docker запускает сервисы в фоне и после перезагрузки при включённом автозапуске Docker.

**Обновление:** повторите команду установки — `data/` сохраняется. Перед обновлением V1 сделайте резервную копию и остановите старые процессы: [инструкция](DEPLOYMENT.md).

**Повторная настройка:** `cd ~/tg-antidel-bot && bash start.sh --setup`.

## Настройка пабликов

Сохраняются только каналы, на которые вы подписаны. Простой просмотр канала не включает его в архив.

В боте откройте **«🎯 Отключить точечно»** или `/channels`: листайте список и отдельно переключайте сохранение или уведомления для каждого канала. В этом разделе ввод `@логина` отключает оба режима сразу; вне раздела он не меняет настройки. Уже сохранённые данные остаются. Общий фильтр уведомлений пабликов продолжает действовать.

## Безопасность и ограничения

**Ваш сервер, ваш аккаунт и ваши API-ключи.** Токен бота уведомлений сам по себе не даёт доступа к личному Telegram-аккаунту и базе переписки на сервере.

- База, медиа, ключи и Telegram-сессия хранятся на вашем сервере. Резервные копии также содержат секреты.
- Сохранённые копии отправляются в ваш Telegram-архив. Локальная очистка не удаляет уже отправленные копии.
- Временная форма настройки защищена ключом из ссылки и закрывается после завершения.
- Контейнеры работают без дополнительных capabilities, с файловой системой образа только для чтения. Папка данных доступна для записи; host networking не изолирует сеть.
- Сеть, лимиты Telegram и свободное место влияют на сохранение. Абсолютная полнота архива и отсутствие дублей не гарантируются.

**Рекомендация по размещению:** используйте доверенную локальную сеть. Не рекомендуется поднимать сервер на хостинге или открывать в общий доступ.
